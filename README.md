# PR Balancing
An initiative, to balance maps.

This repository contains every map that has at least 1 AAS layer. It lists every asset for every faction on every layer, just like the map gallery. You can edit a file, then commit / pull request, and your changes are visible to everyone and can be discussed by anyone. Changes are also perfectly tracked

The goal: Balance assets. Make maps great again.

Proposed changes show up under Pull Requests at the top. In there, you can see Files Changed and thus see the proposed change.

## Layer Rule

Let us make layers great again, as well!

- INF Layer: Lightest layer, least assets or no assets (ideally)
- ALT Layer: "Alternative" layer to STD, a re-interpretation
- STD Layer: The base layer of the map
- LRG Layer: Heaviest layer, most assets

## How to
- Select your map
- Click the edit button (see 1st image)
- Do your changes
- Commit them as Pull Request (see 2nd image)
  - Exact map name in title of Pull Request
  - Describe changes in description Pull Request
- Only ever do 1 Pull Request for 1 map
